Build & limitations ↗
Prototype model Independent C subset · 32-bit int · left-to-right evaluation

This Rust evaluator is independent of bcc’s full C frontend. It supports local integers, pointers, fixed arrays, named calls, and basic control flow. It has no preprocessing, globals, library I/O, or allocation. Nested side effects are rejected. Stores are atomic; deferred effects and full C99 sequencing checks are not implemented. A completed run does not establish that a program is free of undefined behavior.
