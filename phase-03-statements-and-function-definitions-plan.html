01 / Decision

Definitions are not declarations with skipped braces.

Phase 02 already knows how to parse function declarators. Phase 03 gives the body, its block items, and its statements real owners and real syntax nodes.

Core rule

Choose once. Transfer ownership. Parse the whole body.

ExternalDeclarationFrame distinguishes declarations from definitions. From there, every brace, delimiter, scope, and child result has one traceable owner.

  • Prototypes stay declarations. No duplicate function-declaration model.
  • Blocks contain block items. Declarations and statements remain ordered.
  • Scopes unwind exactly. Success, recovery, and EOF restore entry depth.
  • Expressions are typed children. No statement-local expression parser.
  • Recovery is local. The smallest inexact node is marked recovered.

03 / Phase boundary

Structural progress can finish independently.

Statements own expression positions, but they do not duplicate expression grammar. Phase 03 preserves each present expression as an explicit typed deferred child for Phase 04.

Do not blur this line

Deferred children are a phase contract.

Preserve the grammar position, source provenance, focused diagnostic, and parent delimiter explicitly. Syntactic absence remains distinct from a present-but-deferred expression.

Required child contract
  • expression stops before its parent-owned delimiter.
  • constant-expression serves case labels.
  • Optional expressions are represented by the parent.
  • Block and for declarations retain the Phase 02 initializer seam.
  • Phase 04 replaces statement-expression slots and removes initializer seams.

05 / Scope

Broad syntax work, narrow semantic ambition.

The phase completes grammar structure and parser ownership. Type rules and control-flow constraints remain later passes.

In Phase 03
  • Function-definition nodes and external-item variants
  • Prototype-style and old-style definitions
  • Compound statements with mixed block items
  • All C99 statement productions
  • Function, prototype, block, implicit, and label scopes
  • Delimiter recovery, EOF, and translation-limit tests
Later work
  • Phase 04 expression, type-name, or initializer implementation
  • Type checking and return-type validation
  • Full control-flow and label constraint analysis
  • GNU statement expressions and other extensions
  • Backend lowering and code generation
  • An aggregate translation-unit frame without caller demand
06 / Ownership

Every decision and delimiter has one owner.

This map is the review shorthand for detecting token theft, duplicated grammar, and scope leaks.

OwnerResponsibility

DeclarationFrameSemicolon declarations at file, block, for, and old-style positions.
FunctionDefinitionFrameOptional old-style declaration list, function-scope setup, and body child.
CompoundStatementFrameBoth braces, block scope, recovery at the owning brace, and ordered block items.
StatementFrameStatement keywords, punctuation, dangling else, and nested statement children.
