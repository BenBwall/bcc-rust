# Recovery parity and Windows reserved-stack follow-up

Status: investigation in progress. This follow-up addresses the ten malformed
cases recorded in `parser-reserved-stack.md`, and Windows validation requested
by the owner. The production parser remains unchanged by study-only fixes.

Initial reproduction uses the preserved
`.scratch/parser-study/reserved-release-grammar-inspections` snapshots. The ten
cases cover missing or stray header operands, grouped expression synchronization,
unowned closing delimiters, missing call separators, missing `if` bodies,
missing `while` after `do`, and extra `for` header clauses. Some differences lose
following statements or detach an `else`; they are not only message differences.

The available host is Linux. Neither Windows Rust targets nor Wine are initially
installed. `build_support/native.rs` explicitly requires `TARGET == HOST`, so a
full compiler cross-build is unsupported. An isolated harness can compile the
actual example-only Windows reserved-stack module without altering the compiler
build. Wine results, if obtained, will be identified as compatibility-layer
checks and will not be used as native Windows performance evidence.

Study-only fixes now seed expression recovery with the already parsed operand,
retain statement else ownership across recursive/hybrid calls, represent absent
header operands as missing slots, preserve the next statement after a missing
`while`, and reuse bounded `for`-header lookahead. Validation is pending.

Windows GNU strict Clippy passes for the isolated probe. Initial linking
requires the MinGW `dlltool` utility in addition to import libraries. The
first expanded regression run found a duplicate diagnostic on a hybrid handoff;
the prototype now tracks whether the frame already finished recovery.

Debug validation: all 1,050 grammar runs (150 cases × seven modes) match the
frame machine byte-for-byte, including ASTs, provenance and diagnostics. The
seven focused study tests pass, including 20 recovery snippets across recursive,
growing, and hybrid depths 0–16. Release validation is pending.

## What the ten differences were

The original baseline snapshots remain in
`parser-reserved-stack-data/reserved-{release,debug}-grammar.json`.
The sources are generated by `scripts/parser_study_cases.py`; every malformed
function has a following `return` and file-scope declaration so accidental input
consumption is observable. These are ten failing cases, not ten independent
root causes.

| Case suffix (`bad-*.c`) | Prototype behavior before this follow-up | Repair now matched to machine |
| --- | --- | --- |
| `stray-operand-group` | Ends `(a b)` at `a`, leaks `b)` into later statements | Reports stray operator position, skips to owned `)`, marks operand recovered |
| `mismatched-close` | Leaks unowned `]` into a separate null statement | Expression owner diagnoses and consumes stray closer |
| `missing-call-comma` | Closes call early, leaks remaining arguments | Diagnoses missing separator and retains subsequent arguments |
| `if-empty-condition` | Builds an error-expression, generic message | Missing expression slot and `if`-specific message |
| `if-stray-operand` | Treats stray operand as then-body; detaches else | Synchronizes to header `)`, retains then/else |
| `if-missing-body` | Missing then-body consumes `else` | Missing body leaves enclosing if's `else` unconsumed |
| `while-header-brace` | Omits operator diagnostic/recovered flag in body | Matches expression owner and statement-boundary repair |
| `do-missing-while` | Consumes following assignment as condition | Missing condition; following assignment remains a statement |
| `for-extra-clause` | Extra separator becomes null loop body | Bounded scan skips extra header clause through owned `)` |
| `switch-condition` | Leaks stray operand and closes switch scope early | Header synchronization retains switch body and label ownership |

The implementation reuses expression-frame recovery with an already built
operand, pooled storage, and the original error count. It does not rewind,
reparse, or duplicate the successfully built subtree. An explicit marker avoids
running the same recovery twice after a hybrid handoff. Recursive statement
calls and frame handoffs now carry `else` ownership; compounds start fresh.
Missing header operands use `ExpressionSlot::Missing`. The `do` repair uses the
existing diagnostic variant, and the `for` repair shares the frame's bounded
lookahead scanner. Production grammar behavior is unchanged.

The regression test also checks nested then-bodies through `while`, `for`,
`do`, labels, and nested `if`, missing conditions for each header family, a
missing `while` with a visible parenthesized condition, and multiple missing
call commas. It compares complete rendered AST/provenance/diagnostic output
at every hybrid threshold 0 through 16, plus recursive and growing modes.
